# BOSS v9.4.24

**Release Date:** 2026-08-21

A packaging release. The only commits between v9.4.23 and v9.4.24 are the version bump and v9.4.23's own release notes, so no application code changed and this build is functionally identical to v9.4.23.

> **macOS 13.0 (Ventura) or later is required**, unchanged from v9.4.0 - the bundled JxBrowser 9.4.0 engine declares `LSMinimumSystemVersion 13.0`.

## Highlights

- **Nothing behavioural changed.** `git log v9.4.23..v9.4.24` is two commits: the patch bump to 9.4.24 and the documentation commit that added `docs/release-notes/v9.4.23.md`. The diff touches `version.properties`, that new file and the release-notes index, and no source set at all. If you are already on v9.4.23 there is no fix or feature here to move for
- **v9.4.23 is where the substance is.** The dead-browser-handle freeze, the browser page event channel, org-scoped plugin publishing and the alert scrollbar fix all shipped there. See [v9.4.23](v9.4.23.md)

## Documentation

- **release-notes**: `docs/release-notes/v9.4.23.md` is published and indexed in `docs/release-notes/README.md`. The notes are written after the tag is cut, so they land in the range of the release that follows rather than the one they describe (5c46670e)

## Known Limitations

- **Every limitation listed for v9.4.23 still applies**, unchanged, because no code moved. Two tabs on one URL are still resolved by iteration order; `lastKnownUrl`'s seeding and update are still untested; a page event script may still be evaluated more than once in one document; the org publish path still cannot reach the BOSS store; version routes still refuse a plugin whose `author_id` is not the caller
