# BOSS v9.2.60

**Release Date:** 2026-07-25

Fixes browser video fullscreen when the host window is already fullscreen, scopes browser keyboard input to its owning window, and puts the tab bar's "+" button back beside the last tab. Under the hood this is the quality-gate wave: ktlint formats the whole tree with the gate flipped on, detekt gates every module against per-module baselines, and the compiler runs clean.

> This release also carries the v9.2.59 change (browser keyboard scoping, #28), which was built but never published separately.

## Highlights

- **Video fullscreen from a fullscreen window**: page-requested fullscreen no longer fights the host window. A dedicated `FullscreenBrowserWindow` overlay path takes over when the window already fills the screen, transitions are scoped to the owning browser and guarded by a lifecycle epoch so a stale callback can't tear down a newer session, and overlay teardown is guaranteed even when the native exit arrives early or the user re-enters mid-exit (#36).
- **Keyboard input stays in its own window**: a new thread-safe `WindowFocusManager` gates browser key routing on the owner window's focus, so typing in one window no longer leaks into a browser in another (#28).
- **"+" sits next to the tabs again**: in Shrink to Fit mode the new-tab button renders in a trailing slot right after the last tab instead of pinned to the panel's right edge, with the shrink math reserving that slot so tabs never slide under it (#40).
- **Real quality gates**: ktlint formats the entire tree to `ktlint_official` and now fails the build on new violations, detekt gates all 27 modules against frozen baselines, and the last 8 compiler warnings plus the `[HOST-DEBUG]` printlns and per-connection gRPC keepalive warning are gone (#20, #32, #33).

## Bug Fixes

- **browser**: fix video fullscreen requested from an already-fullscreen window - Compose-overlay vs. native fullscreen is chosen from real window/screen geometry, transitions are scoped to the owning browser, deferred work is guarded by session epoch, and overlay cleanup stays queued so teardown is guaranteed across early native exits and exit/re-entry races (#36)
- **browser**: scope keyboard input to the owning window via `WindowFocusManager`, with thread-safe focus lookup and an EDT-enforced listener lifecycle so key routing state can't be observed half-updated (#28)
- **tabbar**: keep the "+" button beside the last tab in Shrink to Fit mode - the LazyRow wraps its content (`weight(1f, fill = false)`), the button renders in a `trailing` slot, and the strip width is measured on the wrapping `Row` so the tabs can grow again when the window widens; legacy Fixed Width mode is untouched (#40)
- **tabbar**: round the divider reserve per rendered piece instead of summing in `Dp` - at 150%/175% display scaling the old math under-reserved ~19px across 20 tabs and flashed the scrollbar; the trailing reserve is now seeded from the button's known width so the first measured frame isn't a slot off (#40)
- **logging**: log every previously swallowed exception - 152 `SwallowedException` and 12 `EmptyCatchBlock` sites now leave a `BossLogger` breadcrumb with no control-flow change; deliberate keeps are renamed `ignored` with a reason. Serialization failures in `LLMSettings` and `PasskeyDataMapper` log the exception class only, since kotlinx error messages can embed API keys or credential material (#25)

## Improvements

- **theme**: finish the `BossDark*` → semantic-token migration across 64 files (~842 deprecation warnings → 0); content on filled `signal`/`alert` surfaces uses `onSignal`, and scrollbar/file-icon colors became getters so they follow theme switches. The deprecated aliases stay for dynamic-plugin compatibility (#22)
- **build**: zero-warning runtime - the last 8 compiler warnings fixed (including a `refreshFromRemote` non-local return that becomes a hard error in Kotlin 2.5), `[HOST-DEBUG]` printlns converted to `BossLogger`, and gRPC's per-connection `SO_KEEPALIVE` warning on unix-domain sockets silenced (#33)
- **style**: format the world - the whole tree and every `*.gradle.kts` reformatted to `ktlint_official` (engine pinned to 1.8.0), the ktlint gate flipped on, and the mechanical commits recorded in `.git-blame-ignore-revs` (#32)
- **ci**: detekt now runs for real and gates on new findings across all modules, with existing debt frozen in per-module baselines; the code-quality job owns detekt + ktlintCheck so the per-OS builds don't triple the work (#20)
- **build**: Gradle 10 readiness - 21 build scripts migrated off the removed `by getting` / `by creating` source-set accessors, and the guarded `plugin-api-ipc` test dependency switched to `project(path)` notation (#21)
- **chore**: delete dead android/ios/wasm source sets and the `iosApp` project (66 files, ~2,386 LOC), the untouched `shared/` KMP template module, tracked `server/bin/` build output, and audit-verified dead constants, vals, and parameters across 22 files (#23)
- **test**: new coverage for the git porcelain parsers (45 tests), workspace extraction from split-view state, shell quoting, and main-branch detection (#24)

## Dependencies

- **build**: version-catalog cleanup - dead Compose entries dropped, `junit-jupiter` 6.1.0 and `clikt` 5.1.0 added and the hardcoded copies replaced, and the 9 microkernel modules moved onto the `graalvmNative` plugin alias (#20)
- **build**: detekt 1.23.8 and ktlint-gradle 14.2.0 applied to all modules (#20)
- **boss-ipc**: align `protoc-gen-grpc-kotlin` codegen to 1.5.0, matching the `grpc-kotlin-stub` runtime (#21)
